# Rare Care Connection — Dúvidas enviadas

Página estática que lista as dúvidas **aprovadas** do evento Rare Care Connection.

Baseado em [duvida-enviada-sea](https://github.com/adrianodesenv/duvida-enviada-sea).

## API

`GET https://connection.eventos-info.com.br/api/duvidas-aprovadas`

Endpoint público do Strapi Connection (status `aprovada` / legado `ativo`).

## Deploy

Publique a pasta (HTML + `assets/`) em qualquer host estático, por exemplo:

`https://connection.eventos-info.com.br/duvida-enviada-connection/`

Não precisa de Node — só arquivos estáticos e CORS liberado na API (já público).
